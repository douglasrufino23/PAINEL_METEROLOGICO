
# 🌤️ Painel Meteorológico

Painel web desenvolvido em **React** e **Vite** para consulta de condições meteorológicas em tempo real e previsão para os próximos dias, consumindo dados da API do OpenWeatherMap.

## 🚀 Tecnologias Utilizadas

- **React** (com Custom Hooks)
- **JavaScript (ES6+)**
- **CSS3** (Responsivo com Grid e Flexbox)
- **OpenWeatherMap API**
- **Vite**

## ⚙️ Funcionalidades

- Consulta de clima em tempo real para múltiplas cidades.
- Painel de alertas e indicadores climáticos (temperatura, umidade, ventos).
- Previsão do tempo detalhada para os próximos dias.
- Possibilidade de alterar e customizar as cidades monitoradas.
